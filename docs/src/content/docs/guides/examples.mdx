Each example is a real form field. The preview, the copied files and the Home demo share one scenario definition, so the options shown in code are the options running in the preview. Type into the field, try the sample values, then open the code.

Every example links to its source on the Examples page. The copied files run in two loading modes. **HTML / CDN** files work after saving them to one folder and opening `index.html` (network access to unpkg is required). **Package / ESM** files import `@samline/formatter` and need a bundler or dev server such as Vite.

## Phones

### Phone by country

`format(value, 'phone', { country })` groups digits for the selected country through `libphonenumber-js`. Changing the country reformats the current digits; the listener reads the country on every call instead of being re-attached.

## Dates and times

### Date for display, ISO for storage

`dateRawPattern` and `dateRawPatternDelimiter` decide the raw shape independently of the display pattern. The default `interpretInputAs: 'auto'` converts a stored `1990-12-31` for display.
