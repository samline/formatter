`@samline/formatter` formats input values and returns **two strings at once**: `formatted` for the visible field and `raw` for the backend. It has no DOM access, no I/O and no state, so it works in browsers, Node.js, React, Vue, Svelte, Shopify themes or anywhere JavaScript runs.

```ts
import { format } from '@samline/formatter'

format('5512345678', 'phone')
// => { formatted: '55 1234 5678', raw: '5512345678', type: 'phone' }
```

## Why Formatter

- **One function, two outputs.** Show `formatted`, submit `raw`, and never re-parse display text on the server.
- **Framework-agnostic.** There is no adapter to install: call it from the input handler you already have.
- **Pure.** No DOM reads or writes, no globals and no clock access, so it is safe on every keystroke.
- **Typed.** `FormatType`, `FormatOptions`, `FormatterResult` and the regex types are exported.
- **Validation included.** The `regex` catalog pairs each pattern with a ready-to-use error message.
- **Built on proven libraries.** Phones use `libphonenumber-js`; the other types use `cleave-zen`. The standalone browser script bundles both.
